# afrodescendant_colonialArt

**Afrodescendants in Colonial Art** is a virtual exhibition exploring how Afro-descendant people were represented in Latin American colonial art, and the places they occupied in viceregal society beyond the condition of enslavement. 

The project is the final assignment for the course *Information Modelling and Web Technologies* (Prof. Fabio Vitali), in the Master's program in Digital Humanities and Digital Knowledge.

Fifteen works drawn from a personal 130-image dataset and the ARCA archive (Universidad de los Andes, Bogotá) are organized into two narrative routes: a general-audience tour that uses cultural identity as an entry point, and a specialist route offering a deeper iconographic and historiographic reading. The site is a static, framework-free build (HTML, CSS, and vanilla JavaScript).

Check out the web exhibition: https://csalguero10.github.io/afrodescendant_colonialArt/index.html
